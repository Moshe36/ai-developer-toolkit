# MCP Configurations

MCP server configs are **machine-local** — they contain absolute paths and machine-specific binaries.
Files here serve as reference/templates, not as portable configs.

## intellij.mcp.json

GitHub Copilot MCP config for IntelliJ IDEA.
The `azmcp.exe` path is machine-specific and must be updated after cloning.

**Destination:** `C:\Users\<you>\AppData\Local\github-copilot\intellij\mcp.json`
