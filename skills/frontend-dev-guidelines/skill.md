# Frontend Development Guidelines

**Stack:** React + TypeScript + Apollo GraphQL + Redux Toolkit + Tailwind + Shadcn UI + Cesium

## When to Use

- Creating new components or pages
- Building new features
- Fetching data with Apollo Client GraphQL
- Managing state with Redux Toolkit
- Styling with Tailwind CSS + Shadcn UI
- Building forms with React Hook Form + Yup
- Integrating 3D maps and geospatial visualization with Cesium

---

## Quick Decision Tree

```
Task?
├─ New Component
│  ├─ Data? → useQuery/useMutation (Apollo)
│  ├─ State? → useState (local) or useAppSelector (global)
│  ├─ Style? → Shadcn component and Tailwind className
│  └─ Form? → useForm + yupResolver + yup schema
│
├─ New Feature
│  ├─ Create features/{name}/ with components/, hooks/, types/
│  ├─ GraphQL ops in backendApi/graphql/operations/{name}/
│  ├─ Run: npm run graphql-typegen
│
├─ Fetch Data
│  ├─ Query → Create custom hook that uses auto generated graphql query hook
│  ├─ Mutation → Create custom hook that uses auto generated graphql mutation hook
│  └─ Real-time → Create custom hook that uses auto generated graphql subscription hook
│
├─ Global State
│  ├─ Create redux/slices/{name}Slice.ts
│  ├─ Use createSlice with reducers
│  └─ Access: useAppSelector/useAppDispatch
│
└─ Style Component
   ├─ UI component exists? → import from '@/components/common/{name}'
   ├─ Conditional classes? → cn("base", condition && "extra")
   └─ Custom? → Tailwind utilities
```

## Essential Checklists

### Component
- [ ] `React.FC<Props>` + TypeScript
- [ ] Apollo: `useQuery`/`useMutation`/`useSubscription` for specific use
- [ ] Redux: `useAppSelector`/`useAppDispatch`
- [ ] Style: Tailwind `className` and Shadcn UI
- [ ] Callbacks: `useCallback` for handlers passed as props
- [ ] Notifications: `toast` from react-hot-toast

### Feature
- [ ] Structure: `features/{name}/(components|hooks|types)/`
- [ ] GraphQL: `backendApi/graphql/operations/{name}/*.graphql`
- [ ] Codegen: `npm run graphql-typegen` after changes
- [ ] Types: Use generated `*Dto` types

## Core Rules

1. **Apollo for data**: useQuery/useMutation as primary pattern
2. **Redux for global state**: Slices with typed hooks
3. **Tailwind + Shadcn**: Utility-first + pre-built components
4. **Features organized**: components/, hooks/, types/ subdirs
5. **TypeScript strict**: No `any`, explicit types
6. **Codegen after changes**: `npm run graphql-typegen`
7. **Toast notifications**: react-hot-toast for all feedback
8. **i18n ready**: useTranslation for user-facing text
